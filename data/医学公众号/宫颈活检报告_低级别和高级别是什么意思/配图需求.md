## 风格（医荟她统一）

- 文章排版：image-gallery 案例 `layout-yihui-interview`（医荟她 · 专家访谈模板，用于读者问答稿）。在 image-gallery 项目的 `wechat/styles.json` 按 ID 读取 `instructions`、`css`、`template` 和 `componentDefinitions`，复用完整模板与组件 HTML：HOT 医荟她栏目条 → 描边阴影导语 → 按轮次重复的左侧提问气泡、右侧回答气泡与通栏图片 → 滚动参考文献 → 资料说明 → END、医荟她落款与科普声明 → 整理署名；头像用模板的「问」「答」文字徽标，不放真人头像。
- 正文配图（概念插图、流程图、数据图）：image-gallery 案例 `canghe-article-scientific`（科学图解）。按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-scientific.webp`。白底、精细线条、分区标注和分色结构，整体沿用该案例，只换本篇已核实的内容，不与其他案例拼接。
- 数据图和流程图：图中文字和数字必须与下方清单逐字一致，不增不减、不自行改写；生成后逐项核对，任何一个数字或标签不对就重做；比例条、柱子等图形长短要与数值相符。
- 封面：image-gallery 案例 `canghe-cover-sketch-notes`（手绘知识笔记封面），参考样图 `assets/style-previews/canghe-cover-sketch-notes.webp`（按 封面轮换.md 选定）。整体沿用该案例的构图、配色、材质和文字层级，只换成本篇主题；样图里的英文或示例文字只学风格不照抄，封面文字只用中文建议标题和副标题；约 2.35:1 横幅，重新为中文标题留出安全区域，不拉伸或裁切样图，不拿正文图充当封面。
- 通用：图中文字用中文，清晰无错字；不画真实医生或患者头像、官方 Logo、二维码、小程序或光愈在线元素；不画仿真病理、惊悚画面或夸大疗效；机制图不把相关画成因果。
