# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。

## 风格（医荟她统一）

- 文章排版：image-gallery 案例 `layout-current`（医荟她 · 已确认文章模板，版本 yihui-confirmed-20260924）。在 image-gallery 项目的 `wechat/styles.json` 按 ID 读取 `instructions`、`css`、`template` 和 `componentDefinitions`，复用完整模板与组件 HTML：HOT 医荟她栏目条 → 描边阴影导语 → 按内容重复的渐变编号章节卡与正文 → 全部展开的参考文献 → 资料说明 → END、医荟她落款与科普声明；不退化成只套 CSS。
- 正文配图（概念插图、流程图、数据图）：image-gallery 案例 `canghe-article-scientific`（科学图解）。按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-scientific.webp`。白底、精细线条、分区标注和分色结构，整体沿用该案例，只换本篇已核实的内容，不与其他案例拼接。
- 数据图和流程图：图中文字和数字必须与下方清单逐字一致，不增不减、不自行改写；生成后逐项核对，任何一个数字或标签不对就重做；比例条、柱子等图形长短要与数值相符。
- 封面：image-gallery 案例 `canghe-cover-warm-flat`（温暖扁平封面），参考样图 `assets/style-previews/generated/canghe-cover-warm-flat.webp`（按 封面轮换.md 选定）。整体沿用该案例的构图、配色、材质和文字层级，只换成本篇主题；样图里的英文或示例文字只学风格不照抄，封面文字只用中文建议标题和副标题；约 2.35:1 横幅，重新为中文标题留出安全区域，不拉伸或裁切样图，不拿正文图充当封面。
- 通用：图中文字用中文，清晰无错字；不画真实医生或患者头像、官方 Logo、二维码、小程序或光愈在线元素；不画仿真病理、惊悚画面或夸大疗效；机制图不把相关画成因果。

     - 标题：“多囊”不是囊肿
     - 左侧标签：超声上看到的是偏多的小卵泡

     - 右侧区块 1：内分泌
     - 右侧区块 2：代谢
     - 右侧区块 3：卵巢
     - 右侧中央圆环：一种全身性的综合征
     - 底部提示带：2026 年国际共识更名，新名字去掉了“囊肿”

3. `imgs/03-diagnosis-flow.png`（位于「02 诊断主要看三件事，还要先排除别的病」小节，“第三，卵巢‘多囊样’改变”段落之后；类型：流程图）
   - 要表达：诊断的顺序和规则：先排除其他疾病；成年人三项中满足两项；有了前两项就不必再做超声或抗米勒管激素；青少年的要求不同。
   - 构图：自上而下的流程。顶部一个框“先排除其他疾病”，下方分成左右两条并列路径：左“成年人”，右“青少年（初潮后 8 年以内）”。左路径画三个并列方框（排卵异常 / 雄激素偏高 / 卵巢多囊样改变或抗米勒管激素偏高），下面一个汇总框“满足其中任意两项”，旁边一个小注释框。右路径画两个方框并用“＋”连接，下面一个汇总框“两项都要满足”，旁边一个小注释框。两条路径都指向底部一个框“由医生综合判断”。箭头只表示诊断步骤顺序，不表示病程。
   - 图中文字（逐字）：
     - 标题：多囊卵巢综合征怎么诊断
     - 顶部框：先排除其他疾病（甲状腺疾病、高催乳素血症、非经典型先天性肾上腺皮质增生症等）
     - 左路径标题：成年人
     - 左框 1：排卵异常（月经不规律）
     - 左框 2：雄激素偏高（多毛、痤疮、脱发或化验偏高）
     - 左框 3：卵巢多囊样改变，或抗米勒管激素偏高
     - 左汇总框：满足其中任意两项
     - 左注释框：已有前两项时，不必再做超声或查抗米勒管激素
     - 右路径标题：青少年（初潮后 8 年以内）
     - 右框 1：排卵异常
     - 右框 2：雄激素偏高
     - 右汇总框：两项都要满足
     - 右注释框：不用超声或抗米勒管激素诊断；未达标准可视为“风险增加”，之后再评估
     - 底部框：由医生综合判断
     - 底部：数据来源：参考文献[2]
