# 医荟她封面轮换

封面风格每 2 天换一个，按下表顺序循环，全部来自 image-gallery 公众号模块（`wechat/styles.json` 里 kind 为 cover 的案例）。

## 规则

- 起始日期：2026-10-19（第 0 天）。
- 写稿任务按当天台北日期计算：`n = (今天 − 起始日期的天数) // 2`，用下表第 `n mod 表长` 行（从 0 数）。
- 选中的案例写进这篇的 `配图需求.md`「封面」那条；配图任务照那条生成。一篇文章定下来的封面风格以后不再改。
- 想换风格或调整顺序，直接改下表；改了以后从当天起按新表计算。不要放进技术感强、深色或游戏风的案例（蓝图、醒目杂志、黑板、深色氛围、奇幻动画、像素、童趣、霓虹复古），复古纸本只适合医学史话题。
