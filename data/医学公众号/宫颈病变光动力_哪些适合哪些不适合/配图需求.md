# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。

## 风格（医荟她统一）

- 文章排版：image-gallery 案例 `layout-current`（医荟她 · 已确认文章模板，版本 yihui-confirmed-20260924）。在 image-gallery 项目的 `wechat/styles.json` 按 ID 读取 `instructions`、`css`、`template` 和 `componentDefinitions`，复用完整模板与组件 HTML：HOT 医荟她栏目条 → 描边阴影导语 → 按内容重复的渐变编号章节卡与正文 → 全部展开的参考文献 → 资料说明 → END、医荟她落款与科普声明；不退化成只套 CSS。
- 正文配图（概念插图、流程图、数据图）：image-gallery 案例 `canghe-article-scientific`（科学图解）。按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-scientific.webp`。白底、精细线条、分区标注和分色结构，整体沿用该案例，只换本篇已核实的内容，不与其他案例拼接。
- 数据图和流程图：图中文字和数字必须与下方清单逐字一致，不增不减、不自行改写；生成后逐项核对，任何一个数字或标签不对就重做；比例条、柱子等图形长短要与数值相符。
- 封面：image-gallery 案例 `canghe-cover-watercolor`（柔和水彩封面），参考样图 `assets/style-previews/canghe-cover-watercolor.webp`。纸张纹理、自然晕染、柔软边缘；约 2.35:1 横幅，重新为中文标题留出安全区域，不拉伸或裁切样图，不拿正文图充当封面。
- 通用：图中文字用中文，清晰无错字；不画真实医生或患者头像、官方 Logo、二维码、小程序或光愈在线元素；不画仿真病理、惊悚画面或夸大疗效；机制图不把相关画成因果。

## 正文配图

1. `imgs/01-transformation-zone-types.png`（位于「04 “转化区”看不看得清，为什么这么重要」小节开头；类型：概念插图，概念示意）
   - 要表达：宫颈转化区按鳞柱交界的位置和能否完全看清分为三型；1 型、2 型能完全看清，3 型在宫颈管内看不全。看不全时病变上边缘可能藏在宫颈管里。
   - 构图：三栏并排，每栏一个简洁、非写实的宫颈纵切面线描示意（宫颈外表面 + 向上延伸的宫颈管，不画仿真组织、不画病变外观、不画血腥色彩）。外侧鳞状上皮用浅粉色线条，宫颈管内柱状上皮用浅橙色线条，两者交界处用一条醒目的蓝绿色虚线标“鳞柱交界”。1 型：交界线位于宫颈外表面；2 型：交界线位于宫颈管口内侧、仍在视线范围内（画一个小眼睛图标和视线虚线能到达交界线）；3 型：交界线深入宫颈管、视线虚线到不了，交界线一半用灰色表示“看不到”。三栏下方各一个状态小标签：1 型、2 型用绿色勾，3 型用灰色问号（不用红色叉，避免恐吓）。
   - 图中文字（逐字）：
     - 标题：宫颈转化区的三种类型
     - 通用标签：鳞状上皮　柱状上皮　鳞柱交界
     - 第 1 栏标题：1 型
     - 第 1 栏说明：鳞柱交界在宫颈外表面，完全看得见
     - 第 1 栏状态：完全可见
     - 第 2 栏标题：2 型
     - 第 2 栏说明：鳞柱交界部分或全部进入宫颈管，仍能完全看见
     - 第 2 栏状态：完全可见
     - 第 3 栏标题：3 型
     - 第 3 栏说明：鳞柱交界在宫颈管内，只能看到一部分或完全看不到
     - 第 3 栏状态：不能完全看见
     - 底部提示带：光动力等保守性治疗，至少要求转化区和病灶完全可见
     - 底部：概念示意　资料：参考文献[1][8]

2. `imgs/02-pdt-eligibility-check.png`（位于「05 哪些情况通常不考虑光动力」小节开头；类型：流程图）
   - 要表达：医生考虑光动力前依次核对的条件；任一条不满足，就转向其他处理方式。这是评估核对的顺序，不是疾病进展路径。
   - 构图：自上而下的竖向核对流程（适合手机屏幕），顶部起点框，下面 4 个依次排列的“是 / 否”判断框，每个判断框向下的“是”箭头通往下一步（蓝绿色），向右的“否”箭头通往右侧一个统一的灰色结果框。最底部是绿色结论框。右侧单独一个浅灰色竖条列“通常不选或需慎重”的情况清单。判断框之间只用简洁箭头，不加任何清单外文字。
   - 图中文字（逐字）：
     - 标题：考虑光动力之前，先核对这几条
     - 起点框：活检病理确诊：宫颈上皮内瘤变 2 级
     - 判断 1：已排除浸润癌和腺上皮病变？
     - 判断 2：鳞柱交界和病变上边缘完全看得见？
     - 判断 3：宫颈管内没有高级别病变？
     - 判断 4：不在怀孕或哺乳期，无卟啉症，对药物和光源不过敏？
     - 每个判断向下箭头：是
     - 每个判断向右箭头：否
     - 右侧结果框（“否”汇合处）：不宜选择光动力，由医生评估其他方案
     - 底部结论框：可以和医生讨论：保守观察、光动力或切除性治疗
     - 右侧清单标题：通常不选或需慎重
     - 右侧清单 1：病变范围较大：需慎重
     - 右侧清单 2：绝经后：首选切除性治疗
     - 右侧清单 3：怀孕期间：以随访为主，产后评估
     - 底部：资料：参考文献[1][2]

3. `imgs/03-three-options.png`（位于「06 光动力、观察随访和切除，怎么取舍」小节开头；类型：概念插图，概念示意）
   - 要表达：宫颈病变 2 级的三种处理方式各自适合谁、优点和需要注意的地方；三者并列，不分高下，不画箭头表示先后。
   - 构图：三张并列的竖向卡片（手机端可上下排列），每张卡片顶部一个简洁线描图标：保守观察（日历加放大镜）、光动力治疗（一束柔和红光照在一个圆形区域上）、切除性治疗（简洁的手术剪刀轮廓，线条柔和，不画血）。卡片配色分别为浅蓝、浅杏、浅紫。每张卡片内三行：“适合谁”“优点”“要注意”。不加任何数字。
   - 图中文字（逐字）：
     - 标题：宫颈病变 2 级的三种处理方式
     - 卡片 1 标题：保守观察
     - 卡片 1 适合谁：25 岁以下优先；有生育需求、条件符合并能按时复查者
     - 卡片 1 优点：不少病变可自然消退，不损伤宫颈
     - 卡片 1 要注意：6 个月、12 个月复查；病变加重、持续 2 年或看不清时转为切除
     - 卡片 2 标题：光动力治疗
     - 卡片 2 适合谁：年轻、有生育需求，病变看得清，已排除浸润癌和腺上皮病变
     - 卡片 2 优点：对宫颈结构影响小
     - 卡片 2 要注意：并非人人有效；需复查，疗程结束时做病理评估
     - 卡片 3 标题：切除性治疗
     - 卡片 3 适合谁：不符合观察条件、绝经后、不能排除更重病变者
     - 卡片 3 优点：疗效确切，可获得完整病理
     - 卡片 3 要注意：切得越深，以后早产风险越高
     - 底部提示带：选择哪一种，由医生结合病理、阴道镜所见、年龄和生育计划评估
     - 底部：概念示意　资料：参考文献[1][2][5]
