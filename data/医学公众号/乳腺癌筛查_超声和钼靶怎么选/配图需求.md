# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。

## 风格（医荟她统一）

- 文章排版：image-gallery 案例 `layout-current`（医荟她 · 已确认文章模板，版本 yihui-confirmed-20260924）。在 image-gallery 项目的 `wechat/styles.json` 按 ID 读取 `instructions`、`css`、`template` 和 `componentDefinitions`，复用完整模板与组件 HTML：HOT 医荟她栏目条 → 描边阴影导语 → 按内容重复的渐变编号章节卡与正文 → 全部展开的参考文献 → 资料说明 → END、医荟她落款与科普声明；不退化成只套 CSS。
- 正文配图（概念插图、流程图、数据图）：image-gallery 案例 `canghe-article-scientific`（科学图解）。按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-scientific.webp`。白底、精细线条、分区标注和分色结构，整体沿用该案例，只换本篇已核实的内容，不与其他案例拼接。
- 数据图和流程图：图中文字和数字必须与下方清单逐字一致，不增不减、不自行改写；生成后逐项核对，任何一个数字或标签不对就重做；比例条、柱子等图形长短要与数值相符。
- 封面：image-gallery 案例 `canghe-cover-watercolor`（柔和水彩封面），参考样图 `assets/style-previews/canghe-cover-watercolor.webp`。纸张纹理、自然晕染、柔软边缘；约 2.35:1 横幅，重新为中文标题留出安全区域，不拉伸或裁切样图，不拿正文图充当封面。
- 通用：图中文字用中文，清晰无错字；不画真实医生或患者头像、官方 Logo、二维码、小程序或光愈在线元素；不画仿真病理、惊悚画面或夸大疗效；机制图不把相关画成因果。

## 正文配图

1. `imgs/01-national-screening-flow.png`（位于「02 国家的乳腺癌筛查怎么做：先超声，必要时再做钼靶」小节，“筛查对象”段落之前；类型：流程图）
   - 要表达：国家乳腺癌筛查项目的分步流程，以及乳腺彩超、乳腺 X 线检查各分类结果对应的下一步。
   - 构图：自上而下的流程图。顶部起点框 → 知情同意、登记 → 乳腺体检 → 乳腺彩色超声检查；彩超下方横向三个分支框（按分类分组），其中“0 类 / 3 类”分支向下连到“乳腺 X 线检查”；X 线下方再横向三个分支框。用浅绿（1/2 类）、浅黄（0/3 类）、浅橙（4/5 类）区分分组，色彩柔和，不用红色警示风格。“1 类 / 2 类”分支用回环细箭头指回“定期筛查”。这是检查流程，不是病程进展，不画疾病发展箭头。
   - 图中文字（逐字）：
     - 标题：国家乳腺癌筛查流程
     - 起点框：35~64 岁女性
     - 步骤框：知情同意、登记
     - 步骤框：乳腺体检（视诊、触诊）
     - 步骤框：乳腺彩超（按 BI-RADS 分类评估）
     - 彩超分支 1：1 类 / 2 类 → 原则上每 2~3 年筛查一次
     - 彩超分支 2：0 类 / 3 类 → 乳腺 X 线检查
     - 彩超分支 3：4 类 / 5 类 → 活检及组织病理学检查
     - 步骤框：乳腺 X 线检查（按 BI-RADS 分类评估）
     - X 线分支 1：1 类 / 2 类 → 遵医嘱定期复查
     - X 线分支 2：0 类 / 3 类 → 专科医生综合评估：短期随访、活检或其他检查
     - X 线分支 3：4 类 / 5 类 → 活检及组织病理学检查
     - 回环箭头标签：定期筛查
     - 底部：数据来源：参考文献[1]

2. `imgs/02-risk-based-screening.png`（位于「03 超声和钼靶，分别适合谁」小节，第一段之后；类型：流程图）
   - 要表达：按《中国女性乳腺癌筛查与早诊早治指南（2021，北京）》，先判断风险分层，再对应不同的起始年龄、间隔和检查方式。
   - 构图：顶部一个判断框，向下分成左右两列。左列蓝绿色系“一般风险女性”，右列紫色系“高风险女性”；每列内三行信息卡（起始年龄 / 筛查间隔 / 检查方式），两列对应行水平对齐便于比较。底部一条浅灰备注带。不画人物。
   - 图中文字（逐字）：
     - 标题：按风险选择乳腺癌筛查方式
     - 顶部判断框：是否属于乳腺癌高风险人群？
     - 左列标题：一般风险女性
     - 左列 起始年龄：从 45 岁开始
     - 左列 筛查间隔：每 1~2 年 1 次
     - 左列 检查方式：可单独做乳腺超声，或考虑单独做乳腺 X 线检查；致密型乳腺：乳腺 X 线 + 乳腺超声联合
     - 右列标题：高风险女性
     - 右列 起始年龄：从 40 岁开始
     - 右列 筛查间隔：每年 1 次
     - 右列 检查方式：乳腺 X 线 + 乳腺超声联合，不推荐单独使用其中一种
     - 底部备注：乳腺核磁不作为一般风险人群常规筛查；BRCA1/2 突变携带者可考虑，但不作为首选
     - 底部：数据来源：参考文献[3]

3. `imgs/03-warning-signs.png`（位于「05 出现这些情况，不要等下一次筛查」小节开头；类型：概念插图，概念示意）
   - 要表达：乳房出现哪些变化需要及时就医，同时提醒大多数肿块不是癌。
   - 构图：中央为简洁、非写实的线描乳房与腋窝示意轮廓（线稿风格，不画真实人体细节、不画病理外观），周围六个小图标卡片，各用一根细引线指向相应部位。底部一条柔和提示带。整体温和，不制造恐慌，不画红色警报或惊悚元素。
   - 图中文字（逐字）：
     - 标题：这些变化，要及时就医
     - 卡片 1：乳房或腋窝肿块、肿胀（常常不痛）
     - 卡片 2：乳房大小或形状改变
     - 卡片 3：皮肤凹陷、发红或颜色变深
     - 卡片 4：乳头内陷，或乳头、乳晕皮疹
     - 卡片 5：非孕期、哺乳期的乳头溢液，尤其带血
     - 卡片 6：腋窝淋巴结肿大
     - 底部提示带：大多数乳房肿块不是癌，但需要医生检查确认　就诊科室：乳腺外科
