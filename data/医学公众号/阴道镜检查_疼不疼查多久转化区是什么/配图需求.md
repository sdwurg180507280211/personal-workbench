# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。

## 风格（医荟她统一）

- 文章排版：image-gallery 案例 `layout-current`（医荟她 · 已确认文章模板，版本 yihui-confirmed-20260924）。在 image-gallery 项目的 `wechat/styles.json` 按 ID 读取 `instructions`、`css`、`template` 和 `componentDefinitions`，复用完整模板与组件 HTML：HOT 医荟她栏目条 → 描边阴影导语 → 按内容重复的渐变编号章节卡与正文 → 全部展开的参考文献 → 资料说明 → END、医荟她落款与科普声明；不退化成只套 CSS。
- 正文配图（概念插图、流程图、数据图）：image-gallery 案例 `canghe-article-scientific`（科学图解）。按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-scientific.webp`。白底、精细线条、分区标注和分色结构，整体沿用该案例，只换本篇已核实的内容，不与其他案例拼接。
- 数据图和流程图：图中文字和数字必须与下方清单逐字一致，不增不减、不自行改写；生成后逐项核对，任何一个数字或标签不对就重做；比例条、柱子等图形长短要与数值相符。
- 封面：image-gallery 案例 `canghe-cover-sketch-notes`（手绘知识笔记封面），参考样图 `assets/style-previews/canghe-cover-sketch-notes.webp`（按 封面轮换.md 选定）。整体沿用该案例的构图、配色、材质和文字层级，只换成本篇主题；样图里的英文或示例文字只学风格不照抄，封面文字只用中文建议标题和副标题；约 2.35:1 横幅，重新为中文标题留出安全区域，不拉伸或裁切样图，不拿正文图充当封面。
- 通用：图中文字用中文，清晰无错字；不画真实医生或患者头像、官方 Logo、二维码、小程序或光愈在线元素；不画仿真病理、惊悚画面或夸大疗效；机制图不把相关画成因果。

## 正文配图

1. `imgs/01-screening-colposcopy-biopsy.png`（位于「01 被叫去做阴道镜，不等于查出了癌」小节开头；类型：流程图）
   - 要表达：筛查、阴道镜检查、组织病理学检查是三个不同的步骤，各自回答不同的问题；初筛异常要做阴道镜的四种情况；被叫去做阴道镜不等于确诊。
   - 构图：从左到右三个大步骤卡片，用细箭头相连（这是检查流程，不是病程进展）。每张卡片上方一个简洁线性图标：卡片 1 试管或采样小图标，卡片 2 放大镜图标（不画真实器械操作场景），卡片 3 显微镜图标。每张卡片下方一句“回答什么问题”。卡片 1 与卡片 2 之间的箭头旁挂一个浅色小清单框，列出转诊阴道镜的四种情况。卡片 3 之后分出一个终点框。底部一条浅灰提示带。柔和青绿、淡紫、浅蓝分色，不用红色警示。
   - 图中文字（逐字）：
     - 标题：筛查、阴道镜、活检，各回答什么问题
     - 卡片 1 标题：宫颈癌筛查
     - 卡片 1 小字：人乳头瘤病毒检测 / 宫颈细胞学检查
     - 卡片 1 问题：有没有风险？
     - 清单框标题：这些情况要做阴道镜
     - 清单框第 1 条：细胞学结果异常或可疑
     - 清单框第 2 条：16 型或 18 型阳性
     - 清单框第 3 条：其他高危型阳性，且细胞学异常或可疑
     - 清单框第 4 条：肉眼看到宫颈异常
     - 卡片 2 标题：阴道镜检查
     - 卡片 2 问题：哪里看起来不对劲？
     - 卡片 2 小字：异常或可疑时取活检
     - 卡片 3 标题：组织病理学检查
     - 卡片 3 问题：是不是病变、什么级别？
     - 终点框：根据病理结果随访或治疗
     - 底部提示带：筛查结果异常不是最后诊断，病理结果才是确定病变的依据
     - 底部：数据来源：参考文献[1]

2. `imgs/02-colposcopy-steps.png`（位于「02 检查当天：大约多久，会经历什么」小节开头；类型：流程图）
   - 要表达：阴道镜检查当天的主要步骤和大致时长，活检和宫颈管搔刮是“必要时”才做的步骤。
   - 构图：自上而下或从左到右的六步时间线，每步一个圆角小卡片加简洁线性图标（检查床、窥器轮廓、滴管、滴管、放大镜、小镊子），步骤 6 用虚线框表示“必要时”。时间线一侧放一个计时小标签。不画人体、私密部位或真实检查场景，不画仿真宫颈或病理图像。
   - 图中文字（逐字）：
     - 标题：阴道镜检查当天会经历什么
     - 步骤 1：躺上妇科检查床
     - 步骤 2：用窥器暴露宫颈
     - 步骤 3：涂醋酸溶液，异常区域会变白
     - 步骤 4：必要时涂碘溶液
     - 步骤 5：放大观察，记录病变和转化区类型
     - 步骤 6（虚线框）：必要时取活检或做宫颈管搔刮
     - 计时标签：检查约 10~20 分钟；取活检约再加 10 分钟
     - 底部提示带：检查中感到不适，可以随时请医生暂停
     - 底部：数据来源：参考文献[2][3][4]

3. `imgs/03-transformation-zone-types.png`（位于「04 报告上的“转化区”和“鳞柱交界”是什么意思」小节开头；类型：概念插图，概念示意）
   - 要表达：转化区三型的区别在于鳞柱交界在宫颈表面还是缩进宫颈管、能不能完全看到；类型描述的是解剖位置，不是病情轻重。
   - 构图：三栏并排，每栏一个简洁的宫颈纵切面示意线稿（不写实，线条风格）：外侧粉色表示鳞状上皮，宫颈管内侧浅红表示柱状上皮，交界处用一条醒目的细线标出“鳞柱交界”，交界附近的浅色带标“转化区”；每栏上方一个小眼睛图标示意“从外面看”，1 型和 2 型的交界线全部在视线可及范围内，3 型的交界线一部分在宫颈管深处，用虚线和“看不到”标出。三栏下方各一句说明。底部一条浅灰提示带。
   - 图中文字（逐字）：
     - 标题：转化区的三种类型
     - 通用标注：鳞状上皮；柱状上皮；鳞柱交界；转化区；宫颈管
     - 第 1 栏标题：1 型
     - 第 1 栏说明：全部在宫颈表面，鳞柱交界完全看得见
     - 第 2 栏标题：2 型
     - 第 2 栏说明：部分伸进宫颈管，鳞柱交界仍能完全看到
     - 第 3 栏标题：3 型
     - 第 3 栏说明：伸进宫颈管，鳞柱交界不能完全看到
     - 第 3 栏虚线处标注：看不到
     - 底部提示带：转化区类型说的是位置，不是病情轻重
     - 底部：概念示意　资料：参考文献[2][5][6]

4. `imgs/04-scj-across-life.png`（位于「05 绝经后为什么更容易“看不全”？孕期能不能做」小节开头；类型：概念插图，概念示意）
   - 要表达：鳞柱交界的位置会随年龄变化，绝经后多缩进宫颈管，因此更难完全看到。这是正常的生理变化，不是疾病进展。
   - 构图：横向两到三个并排的宫颈纵切面线稿，下方一条浅色的年龄带（只写阶段名称，不写具体年龄数字），分别对应“育龄期”“围绝经期”“绝经后”；鳞柱交界细线从宫颈外表面逐步移到宫颈管内。三幅图之间不用粗的单向进展箭头，只在下方年龄带上用细线分段。不画人物，不画病变，不用警示色。
   - 图中文字（逐字）：
     - 标题：鳞柱交界会随年龄“往里走”
     - 第 1 幅标签：育龄期
     - 第 1 幅说明：鳞柱交界多在宫颈表面，容易看到
     - 第 2 幅标签：围绝经期
     - 第 2 幅说明：逐渐移向宫颈口
     - 第 3 幅标签：绝经后
     - 第 3 幅说明：多缩进宫颈管，常常看不全
     - 通用标注：鳞柱交界；宫颈管
     - 底部提示带：这是正常的生理变化；绝经后做阴道镜，更要按医生要求完成后续检查
