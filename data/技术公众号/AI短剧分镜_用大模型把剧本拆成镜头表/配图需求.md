# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。都是示意图，不画真实截图或假界面。

## 风格（技术号统一）

- 正文配图：image-gallery 案例 `canghe-article-editorial`（杂志信息图）。在 image-gallery 项目的 `wechat/styles.json` 里按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-editorial.webp`。整体沿用其构图、配色、线条和文字层级，只替换本篇内容，不与其他案例拼接。
- 封面：与正文同一案例，改成约 2.35:1 横幅，单独留出中文标题区；不拉伸样图，不拿正文图充当封面。
- 图中文字：用中文，标签短而少，保证清晰无错字；不画假界面、假数据、精确按钮或不存在的功能。

## 正文配图

1. `imgs/01-workflow.png`（位于「整个流程长什么样」开头）：横向流程，四个节点用箭头连接：① 一页剧本（纸张图标）→ ② 角色卡与场景卡（两张卡片图标）→ ③ 镜头表（表格图标）→ ④ 逐镜提示词（多段文字条图标），最后箭头指向一个摄影机图标，标“交给视频工具生成”。前三步下方用一个括号框住，标“在对话大模型里完成 · 不耗视频积分”；最后的摄影机下方标“这一步才花积分”
2. `imgs/02-compare.png`（位于「三种拆法，比一比」开头）：三列对比卡片：自己手写、用对话大模型拆、平台自带分镜功能；每列四行短标签——上手（难 / 易 / 最易）、可控（最高 / 高 / 看平台）、换工具（能 / 能 / 一般不能）、适合谁（有拍摄经验 / 大多数新手 / 想最快出片）。中间一列用浅色高亮，标“推荐起点”。不画任何平台 Logo
3. `imgs/03-character-cards.png`（位于「第二步：给每个角色和场景写一张“卡”」开头）：左侧两张卡片：角色卡（条目：年龄外形、发型发色、服装、标志物件）和场景卡（条目：地点、时间、光线、色调）；右侧一列竖排的小方块“镜头 1、镜头 2、镜头 3……”，两张卡各有多条细线连向这些镜头，旁边标“每一镜原样复用”。角色只画剪影或线框人形，不画具体人脸
4. `imgs/04-shot-table.png`（位于「第三步：让大模型拆出镜头表」开头）：一张抽象表格的结构示意，表头依次为：镜号、时长、景别、角度、运镜、画面内容、台词、声音、转场；下面三四行用灰色条代替内容，不写具体数据。表格旁边用小标签提示两条规则：“一镜一个动作”“时长只选工具支持的档位”
5. `imgs/05-row-to-prompt.png`（位于「第四步：把每一行改写成视频提示词」开头）：左边是一行镜头表（简化成几个格子），右边是一段提示词被分成六个色块：镜头、主体、动作、场景、风格、声音。用连线表示来源：景别/运镜 → 镜头；角色卡 → 主体；画面内容 → 动作；场景卡 → 场景；声音列 → 声音；风格块标“全片统一”。声音块与其他块之间留一点间隔，标“单独一句”
