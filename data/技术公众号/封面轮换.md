# 小团子Java 封面轮换

封面风格每 3 天换一个，按下表顺序循环，全部来自 image-gallery 公众号模块（`wechat/styles.json` 里 kind 为 cover 的案例）。正文配图不跟着换，仍用 `canghe-article-editorial`。

## 规则

- 起始日期：2026-10-20（第 0 天）。
- 写稿任务按当天台北日期计算：`n = (今天 − 起始日期的天数) // 3`，用下表第 `n mod 表长` 行（从 0 数）。
- 选中的案例写进这篇的 `配图需求.md`「封面」那条；09:00 的配图任务照那条生成。一篇文章定下来的封面风格以后不再改。
- 想换风格或调整顺序，直接改下表；改了以后从当天起按新表计算。醒目杂志（`canghe-cover-bold-editorial`）没有原始提示词，暂不放进来；水彩、自然疗愈、温暖扁平等偏医学和生活的风格留给医荟她。
