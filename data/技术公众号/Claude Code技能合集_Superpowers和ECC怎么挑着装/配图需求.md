# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。都是示意图，不画真实截图或假界面。

## 风格（技术号统一）

- 正文配图：image-gallery 案例 `canghe-article-editorial`（杂志信息图）。在 image-gallery 项目的 `wechat/styles.json` 里按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-editorial.webp`。整体沿用其构图、配色、线条和文字层级，只替换本篇内容，不与其他案例拼接。
- 封面：与正文同一案例，改成约 2.35:1 横幅，单独留出中文标题区；不拉伸样图，不拿正文图充当封面。
- 图中文字：用中文，标签短而少，保证清晰无错字；不画假界面、假数据、精确按钮或不存在的功能。

## 正文配图

1. `imgs/01-two-collections.png`（位于「先看清两者是什么」开头）：左右对照。左边“Superpowers”画成一条首尾相连的流水线，依次标“问清需求 → 写计划 → 先写测试 → 实现 → 审查 → 收尾”；右边“ECC”画成一个分了很多小格的大工具箱，格子上贴少量短标签：技能、子代理、命令、Hook、规则、记忆、安全扫描。底部一句小字：一个管“怎么做”，一个管“有什么可用”。不画任何品牌 Logo
2. `imgs/02-history.png`（位于「它们是怎么来的」开头）：上下两条平行时间线。上线 Superpowers：2025.10 随插件系统发布 → 进入官方插件市场 → 支持十几种编程智能体。下线 ECC：2025.9 黑客松获胜 → 2026.1 开源 → 2026.6 2.0 正式版 → 2026.10 2.2.3。两条线共享同一个时间轴
3. `imgs/03-compare.png`（位于「横向比一比：该选哪个」开头）：三列对比卡片：Superpowers、ECC、什么都不装；每列四行短标签——定位（固定流程 / 大工具箱 / 原生能力）、规模（十几个技能 / 300 多个技能 / 无）、可拆装（整套装 / 可挑选 / —）、适合（从零做功能 / 要特定能力 / 小修小补）。不做谁“胜出”的打分
4. `imgs/04-context-cost.png`（位于「为什么“别一次全装”」开头）：两个并排的长条形“上下文窗口”。左边装了一个小插件：顶部只有一小段“技能清单”，下面大片空间标“代码和对话”；右边装了一个大合集：顶部一大段“技能清单”，下面空间明显变小。旁边一个小标签：每轮都要带上。不写具体 token 数字
5. `imgs/05-install-superpowers.png`（位于「装 Superpowers：一条命令，整套生效」开头）：三步横向流程：① 从官方插件市场安装（并标注“先看详情页”）→ ② 选安装范围（全部项目 / 只这个项目）→ ③ 开新会话说出想做的东西，它先开始提问。第三步画一个对话气泡里的问号
6. `imgs/06-install-ecc.png`（位于「装 ECC：先想清楚要什么，再挑着装」开头）：上方一个起点“先问顾问：我需要什么”，往下分成三条并列的路（并列选择，不是先后步骤）：完整插件、最小配置（不带 Hook）、按技能挑选。三条路下方一个醒目的提示牌：同一个工具里只选一条
