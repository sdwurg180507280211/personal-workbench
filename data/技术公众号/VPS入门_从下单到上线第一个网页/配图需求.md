# 配图需求

正文共 5 张图，文件放 `imgs/`，文件名与正文引用一致。另需一张独立封面（约 2.35:1）。都是示意图，不要画成某家云厂商的真实控制台截图，也不要画精确按钮。

| 文件 | 位置 | 要表达的内容 |
|---|---|---|
| `imgs/01-what-is-vps.png` | “VPS 到底能拿来干什么？”开头 | 一台机房里 24 小时在线的服务器，四个用途：个人网站/博客、项目后端接口、定时脚本、学习 Linux |
| `imgs/02-before-buying.png` | “下单前，先想好这几件事”开头 | 四个选择：国内（需备案）还是香港/海外（免 ICP 备案、访问速度一般）；配置 1～2 核 2G 起步，Java 项目加数据库看 4G；系统选 Ubuntu LTS；留意续费价 |
| `imgs/03-ssh-key.png` | “把密码登录换成密钥登录”开头 | 自己电脑生成一对密钥：公钥放到服务器，私钥留在本机；登录时两者匹配才放行 |
| `imgs/04-two-firewalls.png` | “第三件，开防火墙”之后 | 两层防护：外层是云控制台安全组，内层是服务器里的 ufw；22/80/443 端口要两层都放行才能通 |
| `imgs/05-first-page.png` | “上线第一个网页”开头 | 访问路径：浏览器 → 公网 IP（或域名）→ 安全组 → ufw → Nginx → `/var/www/html` 网页 |

封面建议标题：**第一次租VPS**，副标题：**从下单到打开自己的网页**。
