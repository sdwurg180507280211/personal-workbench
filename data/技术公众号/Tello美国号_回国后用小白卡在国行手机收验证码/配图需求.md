# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。都是示意图，不画真实截图或假界面。

## 风格（技术号统一）

- 正文配图：image-gallery 案例 `canghe-article-editorial`（杂志信息图）。在 image-gallery 项目的 `wechat/styles.json` 里按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-editorial.webp`。整体沿用其构图、配色、线条和文字层级，只替换本篇内容，不与其他案例拼接。
- 封面：与正文同一案例，改成约 2.35:1 横幅，单独留出中文标题区；不拉伸样图，不拿正文图充当封面。
- 图中文字：用中文，标签短而少，保证清晰无错字；不画假界面、假数据、精确按钮或不存在的功能。

## 正文配图

1. `imgs/01-concepts.png`（位于「先把几个概念说清楚」开头）：三张并排的卡片示意：① 普通实体 SIM 卡（标签：号码写死在卡里）；② 手机内置 eSIM 芯片（标签：扫码下载配置文件）；③ 小白卡，外形像实体 SIM 卡，里面是空白芯片（标签：实体 eUICC 卡，可写入多个配置文件）。右侧一个“配置文件”小图标用箭头写入小白卡。图中标签：实体 SIM、eSIM、小白卡、配置文件
2. `imgs/02-tello-history.png`（位于「Tello 是怎么来的」开头）：横向时间线：2002 KeepCalling 卖国际电话卡 → 2016 推出 Tello Mobile → 支持 eSIM → 支持 Wi-Fi 通话 → 推出国际漫游。时间线末端单独一个提示牌：“新号码须在美国激活”。中间几个节点不标具体年份
3. `imgs/03-compare-options.png`（位于「为什么选 Tello，又为什么可能不选它」开头）：四列对比卡片：Tello、紫卡、原运营商套餐、接码平台；每列三行短标签——月费（最低 5 美元 / 低价 / 几十美元 / 按次）、开通（须在美国激活 / 实体卡渠道 / 已有 / 无需）、号码归属（你的 / 你的 / 你的 / 不是你的）。接码平台一列用灰色或警示色
4. `imgs/04-tello-signup.png`（位于「第一步：注册 Tello，下单 eSIM」开头）：五步流程卡片：注册账号 → 自定义套餐（最低 5 美元）→ 结账选 eSIM → 设置安全 PIN → 在 My SIM 拿到二维码和激活码。最后一步旁边一个小警示：“二维码只能用一次”
5. `imgs/05-write-esim.png`（位于「第二步：把 eSIM 写进小白卡」开头）：左边是安卓手机或读卡器插着小白卡，中间一个“厂商应用”方框，接收来自 Tello 的“二维码 / SM-DP+ 地址 + 激活码”，箭头写入小白卡；右边小白卡插回一台国行手机。图中标签：安卓手机或读卡器、厂商应用、二维码或激活码、写入、插回常用手机
6. `imgs/06-wifi-calling.png`（位于「第四步：设置 E911 地址，打开 Wi-Fi 通话」开头）：两步示意：① Tello 账户里填写美国紧急地址（画一个地址卡片图标，不画具体地址）；② 手机上打开 Wi-Fi 通话开关（抽象开关图标）。下方一条连线：国内 Wi-Fi → 美国运营商网络 → 收到验证码短信
7. `imgs/07-keep-number.png`（位于「怎么保号，号码什么时候会丢」开头）：两条并列的路径：上方“保持月套餐 → 号码一直保留”（绿色）；下方“只剩预付余额 → 3 个月后余额过期 → 7 天宽限期 → 号码永久删除”（逐渐变红）。不画金额和日期
