# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。都是示意图，不画真实截图或假界面。

## 风格（AI短剧统一）

- 正文配图：image-gallery 案例 `canghe-article-editorial`（杂志信息图）。在 image-gallery 项目的 `wechat/styles.json` 里按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-editorial.webp`。整体沿用其构图、配色、线条和文字层级，只替换本篇内容，不与其他案例拼接。
- 封面：image-gallery 案例 `canghe-cover-vintage`（复古纸本封面），与正文案例分开。按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-cover-vintage.webp`。沿用其旧纸张、手绘图鉴风格，画面主体换成本篇主题；约 2.35:1 横幅，单独留出中文标题区；不拉伸样图，不照抄样图里的英文文字，不拿正文图充当封面，不画真实人物或官方 Logo。
- 图中文字：用中文，标签短而少，保证清晰无错字；不画假界面、假数据、精确按钮或不存在的功能。

## 正文配图

1. `imgs/01-four-methods.png`（位于「四种锁角色的办法，比一比」开头）：四列对比卡片，从左到右：纯文字角色卡（文字条图标）、首帧图（单张画框图标）、参考图 Ingredients（几张小卡片图标）、Flow 角色（带声波的人形卡片图标）。每列三行短标签——锁住什么（文字描述 / 整个首帧画面 / 角色道具场景外观 / 外观加声音）、灵活程度（高但易跑偏 / 低 / 高 / 高）、固定声音（不能 / 不能 / 可加人声参考 / 自带）。底部一条从左到右的渐变箭头，标“锁得越来越多”。人形只画线框剪影，不画具体人脸，不画任何 Logo
2. `imgs/02-reference-image.png`（位于「第一步：准备一张合格的角色参考图」开头）：左右两栏对比。左栏标“合格”（打勾）：浅灰纯色背景前一个全身正面站立的线框人形，穿及膝风衣、戴圆眼镜、手拿一小盒牛奶，旁边短标签“纯色背景”“全身正面”“光线均匀”“标志物件可见”。右栏标“不合格”（打叉）：同样的线框人形被杂乱背景、另一个人影和遮挡物包围，只露出半身，标签“背景杂乱”“多人同框”“被遮挡”。人物只画简笔线框，不画具体五官
3. `imgs/03-character-bundle.png`（位于「第二步：在 Flow 里建一个角色」开头）：左侧三块输入：“外观图 1~2 张”（两张小画框）、“角色名”（名牌图标）、“声音”（声波图标），三条线汇入中间一张大的“角色”卡片。右侧从角色卡片引出三条箭头，分别指向“镜头 1”“镜头 2”“镜头 3”三个竖屏小方框，箭头上标“@ 名字调用”。不画产品界面
4. `imgs/04-multi-shot-flow.png`（位于「第四步：把几个镜头串成一场戏」开头）：横向流程六个节点：① 360p 草稿试动作 → ② 挑出满意的一条 → ③ 720p 正式生成 → ④ 暂停保存画面 → ⑤ 作为下一镜参考 → ⑥ Scenebuilder 排序修剪。④到⑤之间画一条回到①的虚线回环，标“下一镜”。①下方小字“消耗约为 720p 一半”，⑥下方画几段首尾相接的胶片条
