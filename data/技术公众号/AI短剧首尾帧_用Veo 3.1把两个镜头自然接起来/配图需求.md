# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。都是示意图，不画真实截图或假界面。

## 风格（AI短剧统一）

- 正文配图：image-gallery 案例 `canghe-article-editorial`（杂志信息图）。在 image-gallery 项目的 `wechat/styles.json` 里按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-editorial.webp`。整体沿用其构图、配色、线条和文字层级，只替换本篇内容，不与其他案例拼接。
- 封面：image-gallery 案例 `canghe-cover-vintage`（复古纸本封面），与正文案例分开。按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-cover-vintage.webp`。沿用其旧纸张、手绘图鉴风格，画面主体换成本篇主题；约 2.35:1 横幅，单独留出中文标题区；不拉伸样图，不照抄样图里的英文文字，不拿正文图充当封面，不画真实人物或官方 Logo。
- 图中文字：用中文，标签短而少，保证清晰无错字；不画假界面、假数据、精确按钮或不存在的功能。

## 正文配图

1. `imgs/01-four-ways.png`（位于「接镜头的四种办法，比一比」开头）：四列对比卡片，从左到右：剪辑硬切（剪刀图标，两段胶片直接相接）、只给首帧（左端一个画框，右端一个问号）、首尾帧（左右两端各一个画框，中间虚线箭头）、延长视频（一段胶片后面接一段渐淡的胶片）。每列两行短标签——能控制什么（只控制拼接 / 只控开头 / 开头和结尾 / 从结尾续写）、主要风险（动作跳 / 结尾不可控 / 两帧差太远会变形 / 越往后越偏）。首尾帧一列用强调色突出。不画任何 Logo
2. `imgs/02-transition-types.png`（位于「第一步：判断这一镜适不适合用首尾帧」开头）：左右两栏。左栏标“适合”（打勾），四个小图标卡片：“位置变化”（人形线框从左走到右）、“推近拉远”（大画框套小画框）、“时间变化”（月亮变太阳）、“物件出现或消失”（空长椅变成长椅上放一个小盒子）。右栏标“慎用”（感叹号），三个卡片：“跨场景跳跃”（室内与车厢两个不相干的画框）、“多人复杂动作”（三个交错的人形线框）、“长段对白”（多个对话气泡）。人物只画简笔线框，不画五官
3. `imgs/03-frame-pair.png`（位于「第二步：做一对能接得上的首尾帧图」开头）：上下两排对比，每排是“首帧 → 尾帧”两张竖屏小画框。上排标“接得上”（打勾）：两张图背景都是同一家便利店门口和一张木长椅，同样的夜间光线，同一个线框老人（风衣、圆眼镜），首帧老人站在门口手拿小盒子，尾帧小盒子放在长椅上、老人不在画面里；旁边短标签“同画幅”“同光线”“同服装”“只改一两处”。下排标“接不上”（打叉）：首帧是夜晚便利店，尾帧是白天的公交车厢，人物服装颜色也不同；标签“场景不同”“光线不同”“服装不同”。人物只画简笔线框，不画具体五官
4. `imgs/04-relay-chain.png`（位于「第四步：在 Flow 里生成」开头）：横向三段竖屏小胶片，标“镜头 1”“镜头 2”“镜头 3”。每段胶片的最后一格用高亮框标出“尾帧”，一条弯箭头把它连到下一段胶片的第一格，标“保存画面 → 下一镜首帧”。底部一行小字“上一镜的结尾 = 下一镜的开头”。不画产品界面
